# カード在庫管理 Phase 2

Windows向けのローカル在庫管理アプリです。

Phase 2では、Phase 1の基本在庫管理に加えて、検索・作業効率改善の機能を追加しています。

## 起動方法

1. Python 3.11以降をインストールします。
2. このフォルダで `run_app.bat` をダブルクリックします。

コマンドラインから起動する場合は以下を実行してください。

```powershell
python -m app.main
```

## Phase 2で追加したこと

- 折りたたみ式の絞り込み条件
- ジャンル、レア、言語、カード状態の候補選択付き絞り込み
- 大文字小文字、全角半角を同一視した部分一致検索
- 価格見直し用の `30日以上`、`90日以上`、任意日数フィルター
- 一覧ヘッダークリックによる昇順・降順・デフォルト切り替え
- 絞り込み結果の全件スクロール表示
- 一覧上のチェック選択
- 選択商品の一括操作
  - 最終確認日を今日にする
  - 売却済みにする
  - 削除済みにする
- 商品複製
- 最終確認日のカレンダー日付選択
- 表示中の編集可能列に合わせたクイック編集
- 補足欄のスペース区切り自動タグ化
- 一覧表示列の選択と保存
- 価格検索リンク
- 価格検索リンク設定
- 現在の絞り込み条件を反映したCSVエクスポート

## 価格検索リンク設定

設定タブで以下を管理できます。

- ジャンル
- サイト名
- 検索URLテンプレート
- 検索語テンプレート
- 適用モード
- 有効/無効

検索URLテンプレートには `{query}` を含めてください。
適用モードを `買取モードのみ` にした設定は、買取モードでだけ検索先として使われます。
買取モードでは専用設定があればそれを優先し、該当する専用設定がない場合は `全モード` の設定を使います。

検索語テンプレートでは以下を利用できます。

- `{genre}`
- `{card_name}`
- `{set}`
- `{language}`
- `{collector_number}`
- `{condition}`
- `{note}`

例:

```text
検索語テンプレート: {card_name} {set} {collector_number}
検索URLテンプレート: https://example.com/search?q={query}
```

## 注意

SQLiteのDBファイルをGoogle Drive、OneDrive、Dropboxなどの同期フォルダに置いて、複数PCから同時に編集する運用は推奨しません。

複数PCで使う場合は、CSVまたはバックアップで受け渡し、同時編集は避けてください。
