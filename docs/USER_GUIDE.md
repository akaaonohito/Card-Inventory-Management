# カード在庫管理 操作ガイド

この資料は、カード在庫管理アプリの日常操作向けガイドです。

## 起動

1. Python 3.11以降をインストールします。
2. `run_app.bat` をダブルクリックします。

コマンドで起動する場合:

```powershell
python -m app.main
```

## 画面構成

- 在庫一覧: 在庫の確認、絞り込み、編集、一括操作、買取見積表印刷を行います。
- 商品追加: 新しいカード在庫を登録します。
- CSV: CSVインポート、CSVエクスポートを行います。
- 設定: 表示列、作業モード、価格検索リンクを設定します。

## 作業モード

画面右上で作業モードを切り替えられます。

- 管理モード: 通常の販売在庫管理向けです。
- 買取モード: 買取価格、状態、レア、セットなどを確認しやすい表示です。
- 価格見直しモード: 販売価格、買取価格、最終確認日を確認しやすい表示です。

モードごとの表示列と初期ステータスは、設定タブで変更できます。

## 在庫の絞り込み

在庫一覧の絞り込みエリアで、以下の条件を指定できます。

- ジャンル
- カード名
- レア
- セット
- 言語
- コレクター番号
- 補足
- カード状態
- 在庫ステータス
- 登録日、更新日、最終確認日
- 価格見直し日数

テキスト検索は、大文字小文字、全角半角の違いをある程度吸収して検索します。

## 編集

- 行を選択して `詳細編集` を押すと、詳細編集画面を開けます。
- 行をダブルクリックすると、表示中の編集可能列をその場でクイック編集できます。
- `複製` を押すと、選択した在庫を新しい在庫IDで複製します。
- `確認日を今日にする` で、選択行の最終確認日を当日に更新します。

補足欄に `Foil プロモ` のように空白区切りで入力すると、保存時に `#Foil #プロモ` のようなタグ形式へ整形されます。

## 一括操作

在庫一覧の `選択` 列でチェックを付けると、一括操作の対象にできます。

- チェック全選択
- チェック全解除
- 選択確認日を今日にする
- 選択を売却済みにする
- 選択を削除済みにする

## 買取見積表印刷

在庫一覧の `買取見積表印刷` を押すと、買取見積表のHTMLを生成してブラウザで開きます。
ブラウザ表示後、印刷ダイアログが自動で開きます。

印刷対象:

- チェック済み行がある場合: チェック済み行
- チェック済み行がない場合: 現在の絞り込み結果

帳票には以下を出力します。

- ジャンル
- カード名
- レア
- 言語
- 補足
- カード状態
- 買取価格
- 枚数
- 買取合計
- 合計枚数
- 合計金額

生成ファイルは `data/purchase_estimate_print.html` です。これは印刷用の一時生成物です。

## CSV

CSVタブからインポート、エクスポートできます。

インポート:

- 通常CSV
- Manabox CSV

Manabox CSVは、`Name`、`Set code`、`Collector number`、`Foil`、`Rarity`、`Quantity`、`Language` などの列から自動判別します。

エクスポート:

- 現在の絞り込み結果をCSVへ出力します。

CSVインポート前には、`data/backups/` にDBバックアップを作成します。

## 価格検索リンク

設定タブで価格検索リンクを登録できます。

設定項目:

- ジャンル
- サイト名
- 検索URLテンプレート
- 検索語テンプレート
- 適用モード
- 有効/無効

検索URLテンプレートには `{query}` を含めます。

検索語テンプレートで使える変数:

- `{genre}`
- `{card_name}`
- `{set}`
- `{language}`
- `{collector_number}`
- `{condition}`
- `{note}`

例:

```text
検索語テンプレート: {card_name} {set} {collector_number}
検索URLテンプレート: https://example.com/search?q={query}
```

## データ保存先

在庫データは `data/inventory.sqlite3` に保存されます。

SQLiteのDBファイルをGoogle Drive、OneDrive、Dropboxなどの同期フォルダに置いて、複数PCから同時に編集する運用は推奨しません。複数PCで使う場合は、CSVまたはバックアップで受け渡し、同時編集は避けてください。
