# カード在庫管理 サンプルUI

本実装前に、画面構成と操作感を確認するための静的サンプルです。

## 起動方法

`sample-ui/index.html` をブラウザで開いてください。

サーバーやインストールは不要です。

## 確認できること

- 在庫一覧、コレクター番号・補足を含む絞り込み、ソート
- 大文字小文字、英数字・記号の全角半角を区別しない絞り込み
- 50件ごとのページ切り替え
- 行単位の通常編集、詳細編集、保存、キャンセル
- 行単位の複製と、複製後の即時編集
- 在庫一覧上でチェックした商品の一括操作
- 商品追加フォーム
- CSVインポート前確認の流れ
- CSVエクスポートの流れ
- 価格検索リンク設定、表示列設定の見た目

## 注意

このサンプルはブラウザ上のダミーデータだけで動きます。
SQLite保存、CSVファイル読込、CSVファイル書出しは本実装で作成します。
